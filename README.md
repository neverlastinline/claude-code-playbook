# Claude Code Project Playbook

A personal reference for AI professionals using Claude Code. Open this at the start of any new project and work through it before writing a line of code.

**[View the playbook →](https://neverlastinline.github.io/claude-code-playbook)**

---

## What's inside

The playbook is built around the **4Ds framework** — a structured approach to planning and running projects with Claude Code:

- **Part 1 — One-Time Setup:** Install Claude Code, configure your API key, set global defaults
- **Part 2 — Per-Project Setup:** Initialise Claude Code, write your CLAUDE.md, configure permissions, add MCP servers, set up hooks
- **Part 3 — The 4Ds Planning Ritual:** Work through Delegation, Description, Discernment, and Diligence before building
- **Appendix — Prompt Library:** Annotated prompts for each D, ready to copy and adapt

## Who this is for

This is a personal reference, written for an AI professional with Claude Code in their stack. It assumes you're starting from scratch on a new machine or project and want a repeatable process that sets you up well every time.
